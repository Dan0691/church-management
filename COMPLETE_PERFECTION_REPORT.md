## 🚀 Getting Started (5 Minutes)

### 1. Install Dependencies
```bash
composer install
npm install
```

### 2. Setup Environment
```bash
cp .env.example .env
php artisan key:generate
```

### 3. Database
```bash
php artisan migrate
php artisan db:seed
```

### 4. Start Servers
```bash
# Terminal 1
php artisan serve

# Terminal 2
npm run dev
```

### 5. Access Application
- Frontend: http://localhost:5173
- API: http://localhost:8000/api
- Dashboard: http://localhost:5173/dashboard
